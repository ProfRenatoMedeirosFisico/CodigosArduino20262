# Códigos Arduino — Apostila 2026/2

Repositório oficial dos programas utilizados na apostila de Arduino e Robótica.

## Organização

Os códigos estão organizados por capítulo. Cada arquivo `.ino` corresponde a um programa completo citado na apostila. Trechos curtos usados apenas para explicar sintaxe permanecem no próprio texto didático.

Para usar um programa, abra o arquivo correspondente, copie o código para a Arduino IDE ou baixe o arquivo `.ino`, conecte a placa e confira as ligações indicadas no capítulo antes de carregar o programa.

> **Atenção:** os números dos pinos, bibliotecas e componentes devem ser conferidos com a montagem apresentada na apostila.
